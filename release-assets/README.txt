i1988 - sBot manager v0.0.1

How to run
1. Extract this entire ZIP to a folder you control.
2. Run SBotManager.exe.
3. If your sBot requires administrator rights, run this Manager as administrator too.

Notes
- This is a portable Windows x64 release: no installer is required.
- Keep all files together; do not run the EXE from inside the ZIP.
- Windows may show an Unknown Publisher warning because this preview release is not code-signed.
- Your settings are stored separately under %LocalAppData%\SBotManager.
