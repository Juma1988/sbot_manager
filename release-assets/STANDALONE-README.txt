i1988 - sBot manager v0.0.1 standalone

Run SBotManager.exe directly. This is a self-contained single-file Windows x64 build.

Notes
- No installer and no .NET installation are required.
- If your sBot requires administrator rights, run this Manager as administrator too.
- Settings remain safely outside this EXE under %LocalAppData%\SBotManager.
- Windows may show an Unknown Publisher warning because this preview release is not code-signed.
